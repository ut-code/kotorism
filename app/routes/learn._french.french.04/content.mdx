### 所有形容詞 (私の・君の…)

| 意味                | 男性単数 (の名詞につく) | 女性単数 (の名詞につく) | 複数 (男女共通) |
| ------------------- | ----------------------- | ----------------------- | --------------- |
| 私の                | mon                     | ma                      | mes             |
| 君の                | ton                     | ta                      | tes             |
| 彼の・彼女の        | son                     | sa                      | ses             |
| 私たちの            | notre                   | notre                   | nos             |
| 君たちの (あなたの) | votre                   | votre                   | vos             |
| 彼らの・彼女らの    | leur                    | leur                    | leurs           |

### 所有代名詞 (私のもの・君のもの…)

| 意味                        | 男性単数 | 女性単数  | 男性複数   | 女性複数    |
| --------------------------- | -------- | --------- | ---------- | ----------- |
| 私のもの                    | le mien  | la mienne | les miens  | les miennes |
| 君のもの                    | le tien  | la tienne | les tiens  | les tiennes |
| 彼のもの (彼女のもの)       | le sien  | la sienne | les siens  | les siennes |
| 私たちのもの                | le nôtre | la nôtre  | les nôtres | les nôtres  |

### 冠詞 (le・un・du)

| 種類                            | 男性単数 | 女性単数 | 複数 (男女共通) |
| ------------------------------- | -------- | -------- | --------------- |
| 定冠詞 (その〜)                 | le       | la       | les             |
| 不定冠詞 (ある〜・いくつかの〜) | un       | une      | des             |
| 部分冠詞 (いくらかの〜)         | du       | de la    | des             |

### 指示形容詞 (この〜・その〜)

| 後ろの名詞                         | 形    |
| ---------------------------------- | ----- |
| 男性単数 (子音で始まる)            | ce    |
| 男性単数 (母音・無音の h で始まる) | cet   |
| 女性単数                           | cette |
| 複数 (男女共通)                    | ces   |

### 指示代名詞 (〜のそれ)

| 指すもの | 形     |
| -------- | ------ |
| 男性単数 | celui  |
| 女性単数 | celle  |
| 男性複数 | ceux   |
| 女性複数 | celles |

### 指示代名詞 (これ・それ)

| 意味                       | 形   |
| -------------------------- | ---- |
| これは・それは (être の前) | ce   |
| これ (書き言葉)            | ceci |
| それ・あれ (書き言葉)      | cela |
| それ・これ (話し言葉)      | ça   |
