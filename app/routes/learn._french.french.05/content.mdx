### c'est / il(elle) est の使い分け

| 例文 (問題文)                                   | 日本語訳・ヒント                           | 正解     | 解説                                                                                |
| ----------------------------------------------- | ------------------------------------------ | -------- | ----------------------------------------------------------------------------------- |
| \_ un excellent restaurant.                     | これは素晴らしいレストランです。           | C'est    | 不定冠詞＋名詞（un excellent restaurant）を提示する構文のため C'est を使用します。  |
| Regarde cette voiture ! \_ très rapide.         | あの車を見て！とても速いよ。               | Elle est | 既に話題になっている特定の女性名詞（cette voiture）を形容詞だけで説明するため使用。 |
| \_ trois heures de l'après-midi.                | 午後3時です。                              | Il est   | 時刻を表す非人称構文のため Il est を使用します。                                    |
| \_ médecin, mon frère.                          | 私の兄は医者です。                         | Il est   | 職業を無冠詞の名詞（médecin）だけで述べる場合は Il est を使用します。               |
| \_ mon frère, le médecin dont je t'ai parlé.    | これが私の兄、話していた医者だよ。         | C'est    | 人物を名詞句（mon frère）で紹介・提示する構文のため C'est を使用します。            |
| \_ vrai que Paris est la capitale de la France. | パリがフランスの首都だというのは本当です。 | C'est    | 一般的・非人称的な判断を表す形容詞の前では C'est を使用します。                     |
| \_ très gentille, ta sœur.                      | 君のお姉さん、とても優しいね。             | Elle est | 既知の特定の女性（ta sœur）を形容詞だけで描写しているため使用します。               |
| \_ moi qui ai téléphoné hier soir.              | 昨夜電話したのは私です。                   | C'est    | 強勢形代名詞（moi）を提示する構文のため C'est を使用します。                        |
| \_ tard, il faut rentrer.                       | 遅い時間だ、帰らなくちゃ。                 | Il est   | 時間に関する非人称表現のため Il est を使用します。                                  |
| \_ des amis très fidèles.                       | 彼らはとても忠実な友人たちです。           | Ce sont  | 複数名詞（des amis）を提示するときは、ce も複数形の ce sont に一致させます。        |

### à と pour の使い分け（「～するためのもの」の目的用法）

| 例文 (問題文)                                                        | 日本語訳・ヒント                                   | 正解 | 解説                                                                                   |
| -------------------------------------------------------------------- | -------------------------------------------------- | ---- | -------------------------------------------------------------------------------------- |
| C'est un couteau \_ couper le pain.                                  | パンを切るための包丁です。                         | à    | couteau à pain のように、物の本来備わった固有の用途を表す複合名詞には à を使用します。 |
| J'ai besoin d'un couteau \_ couper cette corde tout de suite.        | 今すぐこのロープを切るためのナイフが必要です。     | pour | その場限りの具体的な目的（今このロープを切る）を表す場合は pour を使用します。         |
| Elle a acheté une machine \_ laver toute neuve.                      | 彼女は真新しい洗濯機を買った。                     | à    | machine à laver（洗濯機）は物の固有の機能を表す固定表現のため à を使用します。         |
| Il a pris son parapluie \_ se protéger de la pluie.                  | 彼は雨から身を守るために傘を持って行った。         | pour | 「～するために」という行為の目的・意図を表す場合は pour を使用します。                 |
| Ce verre \_ vin est en cristal.                                      | このワイングラスはクリスタル製です。               | à    | verre à vin（ワイングラス）はグラスの種類・用途を表す固定表現のため à を使用します。   |
| Elle m'a prêté un verre \_ boire de l'eau.                           | 彼女は水を飲むためのコップを貸してくれた。         | pour | 「その場で水を飲む」という一時的・個別的な目的のため pour を使用します。               |
| Range les brosses \_ dents dans le tiroir.                           | 歯ブラシを引き出しにしまってください。             | à    | brosse à dents（歯ブラシ）は物の用途を表す固定した複合名詞のため à を使用します。      |
| Nous avons besoin de plus de chaises \_ accueillir tous les invités. | すべての招待客を迎えるためにもっと椅子が必要です。 | pour | 「招待客全員を迎える」という具体的な行為の目的を表すため pour を使用します。           |
| Le fer \_ repasser est cassé.                                        | アイロンが壊れている。                             | à    | fer à repasser（アイロン）は道具の固有の用途を表す固定表現のため à を使用します。      |
| Elle utilise cette table \_ écrire ses lettres ce soir.              | 彼女は今夜、手紙を書くためにこのテーブルを使う。   | pour | 「今夜手紙を書く」という一時的・個別の行為の目的を表すため pour を使用します。         |
